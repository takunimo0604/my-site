# 타쿠니모 자기소개 사이트

순수 HTML/CSS/JS로 만든 간단한 자기소개 웹사이트입니다. npm이나 빌드 도구 없이 동작합니다.

## 배포 주소

https://내아이디.github.io/my-site/

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (헤더, 소개, 좋아하는 것 3가지, 푸터) |
| `style.css` | 스타일 (파스텔톤 디자인) |
| `script.js` | 푸터의 연도를 올해로 자동 표시 |

## 로컬에서 보는 방법

1. 이 폴더(`my-site`)를 내려받거나 복제합니다.
2. `index.html`을 더블클릭하거나 브라우저로 끌어다 놓아 엽니다.

별도의 설치나 빌드는 필요 없습니다.

## 섹션

- **헤더:** 이름과 한 줄 소개, 메뉴 링크(소개, 좋아하는 것, 연락처)
- **소개:** 자기소개 문단
- **좋아하는 것 3가지:** 카드 세 개를 세로로 배치
- **푸터:** 저작권 문구와 올해 연도
